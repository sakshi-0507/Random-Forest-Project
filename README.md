# Random Forest Classification

This project is a **Machine Learning classification project** using the Random Forest algorithm.

### What I Did

* Split the data into training and testing sets
* Trained a Random Forest Classifier
* Made predictions on the test data
* Compared the training and testing accuracy

### Results

* Training Accuracy: **100%**
* Testing Accuracy: **92.99%**

The model performed well on the test data, with around **93% testing accuracy**.

### Tools Used

Python, Pandas, NumPy, Scikit-learn, Jupyter Notebook

### Project Goal

The main goal of this project was to understand how Random Forest works and how multiple decision trees can be combined to make predictions.
